# Contributing

Run the source and service tests in [QUICKSTART.md](QUICKSTART.md). Include the
node/chip, macOS, model revision, configuration and artifact hashes when reporting
a reproducible issue. Exclude credentials, private prompts and model weights.
Runtime changes need focused behavioral tests; accelerator changes additionally
need matched device evidence. Keep upstream attribution and native build receipts.

Report JustFit issues to https://github.com/YuhuaBillChen/justfit-llm/issues.
Upstream Splash maintainers are not the support contact for this modified project.
